# Cloudflare Turnstile

En el panel Turnstile, agrega un widget por cliente y elige Managed Mode. Añade los hostnames donde se muestra el formulario, conserva la site key pública y guarda la secret key en .env. Establece TURNSTILE_SITE_KEY, TURNSTILE_SECRET_KEY y TURNSTILE_ALLOWED_HOSTNAMES. En PHP la lista de hostnames es exacta. Turnstile funciona con el DNS y CDN del proveedor que ya utilice el sitio. [Panel de Cloudflare](https://developers.cloudflare.com/turnstile/get-started/widget-management/dashboard/).

El frontend renderiza explícitamente cada widget, usa appearance=interaction-only de forma predeterminada y resetea su token después de cada intento. Puedes compartir site key entre formularios de la instalación y darles acciones distintas con turnstile_action. El servidor compara hostname y acción y verifica cada token una vez. El token caduca a los cinco minutos. Si Cloudflare queda inaccesible el backend responde 503. [API Siteverify](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/) · [Renderizado explícito](https://developers.cloudflare.com/turnstile/get-started/client-side-rendering/).

Para desarrollo usa el catálogo oficial de claves de prueba que aceptan, rechazan o simulan un token consumido. El par de pruebas puede devolver hostname y acción de prueba; ajusta solo una instalación aislada o prueba esa lógica con un mock. Verifica hostname y acción con un widget real autorizado antes de producción. [Claves oficiales de testing](https://developers.cloudflare.com/turnstile/troubleshooting/testing/).

Para rotar, genera una clave nueva desde el panel o la CLI administrativa. Actualiza el servidor dentro de la ventana de dos horas si usaste rotación con período de gracia y realiza un ensayo autorizado. Revocar el widget invalida sus claves. La CLI separada usa permisos Turnstile Sites Read o Turnstile Sites Write según la acción. Sus listados omiten las claves secretas. [Rotación](https://developers.cloudflare.com/turnstile/troubleshooting/rotate-secret-key/) · [API oficial](https://developers.cloudflare.com/api/resources/turnstile/subresources/widgets/).

Según los planes consultados en noviembre de 2026, Free permite hasta 20 widgets por cuenta y 10 hostnames por widget. Enterprise ofrece widgets ilimitados sujetos a condiciones de cuenta y hasta 200 hostnames por widget. Comprueba las cuotas vigentes y las restricciones de cada operación de API al automatizar la creación. [Planes de Turnstile](https://developers.cloudflare.com/turnstile/plans/).
