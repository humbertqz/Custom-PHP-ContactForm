# Apps Script del cliente

Instala Code.gs en el proyecto Apps Script de la hoja del cliente. Configura CONTACT_TOKEN, CONTACT_SPREADSHEET_ID y CONTACT_FORM_MAP en Script Properties. Sigue la [guía para el propietario de la hoja](../../docs/google-sheets.md). El manifiesto declara únicamente el ámbito de Google Sheets requerido por openById.
